# 远程管理功能优化方案 v1.0

> 状态：已评审，进入执行  
> 范围：SSH/SFTP/VNC 远程管理链路（前端 → 信令 → WebRTC DataChannel → wragent/wrgateway → 目标机）  
> 关联：原 `/api/ws/ssh` 已删除，现网为 WebRTC 双模式（agent 直连 / gateway 中继）

---

## 1. 架构现状

```
【直连/Agent 模式】
浏览器 ──WSS /api/ws/webrtc(信令)── FastAPI ──► wragent ──SSH──► 目标机
   └──── WebRTC DataChannel (终端/SFTP/VNC 数据) ────┘

【Gateway 模式】
浏览器 ──WSS :5599?token=── wrgateway ══DC══ wragent ──SSH──► 目标机
   └──── 信令仍走 FastAPI；终端帧走 gateway WS Binary ────┘
```

| 层 | 组件 | 技术栈 | 会话存储 |
|---|---|---|---|
| 前端 | SshManager / webrtc.ts | Vue3 + xterm 6 + RTCPeerConnection | 进程内 `tabs/terminals/webrtcRefs` |
| 信令 | api_isolated.py:1315 | FastAPI WS，进程内 dict | `_online_agents/_gateways/_agent_connections` |
| 网关 | wrgateway | gorilla/ws + pion/webrtc v4 | `sessions map` + `SendCh(4096)` |
| 执行端 | wragent | x/crypto/ssh + pion | `sshPool` + `p map[room]Peer` |
| 协议 | DC 帧 | `[1B prefix][payload]` 0x00–0xFF | 无 seq/ack/version |

## 2. 问题总表

| # | 维度 | 问题 | 位置 | 严重度 | 影响 |
|---|------|------|------|--------|------|
| R1 | Session 错乱 | gateway 心跳/清理用错变量：`register_gateway` 只写 `gw_id`，heartbeat/finally 判断的是 `agent_id`（恒空） | api_isolated.py:1408,1680,1770 | **P0** | 僵尸网关永远"在线" |
