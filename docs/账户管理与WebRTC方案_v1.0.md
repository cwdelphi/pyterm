### 2.2 API 端点设计

| 方法 | 路径 | 功能 | 认证 | 说明 |
|------|------|------|------|------|
| POST | `/api/auth/register` | 用户注册 | 无 | 创建新用户 |
| POST | `/api/auth/login` | 用户登录 | 无 | 返回JWT token |
| POST | `/api/auth/logout` | 用户登录 | 需要 | 销毁会话 |

## 三、WebRTC 远程访问架构

### 3.1 连接模式对比

| 特性 | 直接SSH连接 | WebRTC模式 |
|------|-------------|------------|
| **连接方式** | 浏览器 → 服务器 → SSH | 浏览器 ↔ WebRTC ↔ wragent ↔ SSH |
| **NAT穿透** | 需要端口映射 | 自动穿透（STUN/TURN） |
| **延迟** | 中等（经服务器） | 低（P2P直连） |
| **带宽** | 受服务器限制 | P2P直连带宽 |
| **安全性** | 服务器可见数据 | 端到端加密（DTLS-SRTP） |
| **部署复杂度** | 低 | 中等（需coturn） |
| **适用场景** | 局域网/固定IP | 公网/动态IP/复杂NAT |

## 四、coturn 配置方案

### 4.1 docker-compose.yaml 变更

```yaml
services:
  # 现有服务...
  md:
    # ... 保持不变
  
  # 新增 coturn 服务
  coturn:
    image: coturn/coturn:latest
    container_name: pyterm_coturn
    network_mode: host                # 必须使用host网络
    restart: unless-stopped
    volumes:
      - ./config/turnserver.conf:/etc/coturn/turnserver.conf:ro
    command: -c /etc/coturn/turnserver.conf
    # 端口说明：
    # 3478 (STUN/TURN UDP/TCP)
    # 5349 (TURNS TLS)
    # 49160-49259 (中继端口范围, 100个)
```

### 4.2 turnserver.conf 配置

```conf
# ===== 网络监听 =====
listening-port=3478
tls-listening-port=5349

# ===== 外部地址（必须配置） =====
# 替换为服务器公网IP
external-ip=YOUR_PUBLIC_IP/YOUR_PUBLIC_IP

# ===== 中继端口范围 (100个) =====
min-port=49160
max-port=49259

# ===== 认证方式 =====
# 使用REST API + HMAC（推荐）
use-auth-secret
static-auth-secret=YOUR_SECRET_KEY_HERE

# ===== 安全策略 =====
realm=pyterm.local
fingerprint
lt-cred-mech
no-multicast-peers
no-cli

# ===== TLS =====
no-tlsv1
no-tlsv1_1

# ===== 性能 =====
proc-quota=30
total-quota=100
log-file=stdout
verbose
```

### 4.3 TURN 凭证生成（FastAPI端）

```python
import hmac
import hashlib
import base64
import time

TURN_SECRET = "YOUR_SECRET_KEY_HERE"  # 与turnserver.conf一致

def generate_turn_credentials(username: str, ttl: int = 300) -> tuple[str, str]:
    """生成TURN临时凭证"""
    timestamp = int(time.time()) + ttl
    temporary_username = f"{timestamp}:{username}"
    
    mac = hmac.new(
        TURN_SECRET.encode(),
        temporary_username.encode(),
        hashlib.sha1
    )
    credential = base64.b64encode(mac.digest()).decode()
    
    return temporary_username, credential

def get_ice_servers(user_id: str) -> list[dict]:
    """获取ICE服务器配置"""
    username, credential = generate_turn_credentials(user_id)
    
    return [
        {
            "urls": [
                "stun:stun.l.google.com:19302",
                "stun:stun1.l.google.com:19302"
            ]
        },
        {
            "urls": [
                f"turn:{SERVER_PUBLIC_IP}:3478?transport=udp",
                f"turn:{SERVER_PUBLIC_IP}:3478?transport=tcp",
                f"turns:{SERVER_PUBLIC_IP}:5349?transport=tcp"
            ],
            "username": username,
            "credential": credential
        }
    ]
```

## 八、安全考虑

### 8.1 安全措施

| 威胁 | 措施 | 实现 |
|------|------|------|
| **密码泄露** | bcrypt哈希存储 | 注册/登录时 |
| **JWT伪造** | HMAC-SHA256签名 | JWT生成/验证 |
| **会话劫持** | HTTPS + HttpOnly Cookie | 前端实现 |
| **路径穿越** | 用户ID白名单验证 | API层 |
| **SSH密钥泄露** | 加密存储 | 后端实现 |
| **WebRTC窃听** | DTLS-SRTP加密 | pion/webrtc |
| **TURN滥用** | 临时凭证(HMAC) | coturn配置 |
| **暴力破解** | 登录频率限制 | API中间件 |
