## 一、现状根因（实测）

| 问题 | 实测位置 | 事实 |
|------|----------|------|
| 登录后 403 刷屏 | `AdminPanel.vue:679` `onMounted` | `Promise.all([loadUsers, loadAgents, loadGateways, loadCoturn, loadAudit, loadRoles, loadPendingAgents])` 无条件执行 → 普通账户（`inportb`）产生 3 次 403：`/api/admin/users`(`auth_api.py:109`)、`/api/admin/roles`(`:211`)、`/api/admin/audit`(`:235`)，且 `loadUsers/loadRoles/loadAudit` 还会 `toast.error` 弹错误 |
| 落地页是空的 | `AdminPanel.vue:26` | `activeTab` 默认 `'users'`，普通账户一进系统管理就是无权限 tab |
| 菜单不按权限过滤 | `AdminPanel.vue:15-25` | 9 个菜单全量渲染；`TopBar.vue:49-55` 任何登录用户都显示「系统管理」 |
| 权限矩阵 | `auth.py:37-51` | `admin`＝全 8 项；`user`＝`[ssh:manage, doc:manage, link:manage, agent:manage, coturn:manage]`；**缺** `user:manage / audit:read / system:admin` |
| 分享弹窗名单拉不到 | `AdminPanel.vue:414` `openShareModal` | 调 `api.adminListUsers()`(admin-only) 且 `catch{}` → 普通账户「指定共享」弹窗**空列表** |
| 新增 Agent 必 403 | `auth_api.py:283` `agent-id/next`=require_admin，`POST /agents`(`:390`) 只要 `agent:manage` | 权限自相矛盾，普通账户点「新增 Agent」直接报错 |
| 共享资源操作按钮全亮 | `AdminPanel.vue:873-880` | `openAgentConfig / toggleAgentStatus / openDeployScript / openDeleteAgent / openShareModal / upgradeAgent / copyAgentToken` 均无 `is_owner` 判断；后端 14 处 `owner_id != user["id"]` 已 403 兜底 → 结果是**点了才报错** |
| 机密泄露 | `auth_api.py:302 / 1406 / 666` | 列表对「分享来的」资源仍返回 `token`（agent/gateway）、`secret`（coturn） |
| 来源标注不全 | 列表有、连接表单无 | `AdminPanel.vue:844`、`GatewayManager.vue:185`、coturn `:920` 已有 `owner-tag`；但 `SshManager.vue:1013` Agent 下拉、`:1021` 网关下拉**不显示来源** |
| 日志等级非账户级 | `logger.ts:7-33` | 键 `console_log_level` 全账户共用；UI 在 settings tab（`AdminPanel.vue:1036-1043`，人人可见） |

> 安全面结论：**所有变更类接口后端已有 owner 校验**（`auth_api.py` 14 处），本轮以 UI 门禁 + 读接口机密遮蔽 + 权限矛盾修复为主，非安全洞修补。

## 三、改动清单

### A. 后端 `app/auth_api.py`（3 处）

1. `:283 admin_next_agent_id`：`require_admin` → `require_permission("agent:manage")`（D3）
2. 新增 `GET /api/admin/shareable-users`：`require_permission("agent:manage")`，只返回 `{"users":[{id, username}]}`，排除自己（D5）
3. 机密遮蔽：`admin_list_agents`(`:302`)、`admin_list_gateways`(`:1406`)、`admin_list_coturn`(`:666`) 对 `is_owner==False` 分别返回 `token:""` / `secret:""`

### B. 前端 `AdminPanel.vue`

1. 权限获取：挂载时调 `api.adminMyPermissions()`（`api.ts:397`，目前**死代码**）→ `role/permissions` ref
2. `menuItems` 加 `perm` 字段并过滤（`:15-25`）；`activeTab` 默认改 `agents`（`:26`）；权限未就绪时用骨架/空态避免闪烁
3. `onMounted`（`:679`）按权限门禁 `loadUsers / loadRoles / loadAudit` → 403 与错误 toast 归零
4. Agent 行（`:844-881`）、coturn 行、`GatewayManager.vue` 操作按钮按 2.2 表 `:disabled`/隐藏，统一 tooltip `admin.sharedReadonly`
5. `openShareModal`（`:414`）改调新接口 `api.adminShareableUsers()`；非属主不渲染分享按钮
6. token 单元格（`:857`）：`a.token` 为空显示 `-`、禁复制

### C. 前端 `SshManager.vue`

- Agent 下拉 `:1013` / 网关下拉 `:1021`：`!is_owner` 时追加 `· 属于 {owner_name}`（复用 `admin.fromOwner`）；`agents/gateways` ref 类型补 `is_owner/owner_name`
- **D6 控制台收敛**：新增 `consoleAgents = agents.filter(a => a.is_owner !== false)`，用于「Agent 控制台」分组（计数 / `v-for` / 空态）、`stTargets` 测速目标与 `openSpeedtest` 默认目标；下拉与 `agents.find()` 名称查找仍用全量 `agents`

### D. 日志等级账户级（D2）

- `utils/logger.ts`：键改为 `console_log_level:<uid>`，`uid` 取 `localStorage.user` 的 `id`（`api.ts:71` User 接口含 `id`）
- 首次读该 uid 键缺失时，**继承旧键 `console_log_level` 的值**（保住既有偏好），旧键不删
- 切换账户/登录后重新 `setLogLevel(loadLevel(uid))`；settings 卡片 UI 不变

### E. i18n

- `zh-CN.json` / `en.json` 新增 `admin.sharedReadonly`（分享资源，仅可使用与查看）等 2 键，**716 → 718**，同步 `AGENTS.md:50` 数字

### F. 后端测试 `app/tests/test_share_permissions.py`（新增）

> 用户用 `test_` 前缀 + `delete_user_by_username`（`sync_db._write_users_file` 只清理 `test_` 等前缀）。

- S1：`user` 角色 `GET /users|/roles|/audit` → 403（保持）；`GET /agent-id/next` → 200；`GET /shareable-users` → 200 且只含 id/username、不含自己
- S2：非属主对 `PUT /config`、`/status`、`DELETE`、`/share`、`/token`、`/upgrade` → 403；`GET /config` → 200
- S3：列表对分享来的 agent/gateway 返回 `token==""`、coturn 返回 `secret==""`，`is_owner/owner_name` 正确；自有资源字段原样
- S4：`GET /me/permissions` 返回的 user 权限集合与 2.x 矩阵一致
- 回归：`docker exec -e TESTING=1 pyterm_md python -m pytest app/tests/`（基线 **126 passed / 29 预存在失败**）

## 六、实施结果（2026-09-29）

### 交付内容

**后端 `app/auth_api.py`**

1. `GET /api/admin/agent-id/next`：`require_admin` → `require_permission("agent:manage")`。
2. 新增 `GET /api/admin/shareable-users`：仅返回 `{id, username}`，排除自己，仅活跃账户。
3. 机密遮蔽：非属主的 Agent/Gateway `token` 置空、Coturn `secret` 置空。
4. 属主校验补强（实施中发现的越权缺口，一并修复）：
   - `GET /agents|gateways|coturn/{id}/shares` 非属主 → 403（分享名单属属主管理信息）。
   - `GET /coturn/{id}/test-credentials` 非属主 → 403（避免借中转凭据反查）。
   - `POST /coturn/{id}/default` 非属主 → 403（原实现缺校验，可改他人中转的默认标记）。
   - `POST /agents|gateways/{id}/upgrade` 非属主 → 403（原实现仅校验在线与版本号，可向他人设备下发升级指令）。

**前端**

- `AdminPanel.vue`：`/me/permissions` 拉取 + `can()` 门禁；菜单 9 项按权限过滤；普通账户默认落在 Agent 管理；`onMounted` 仅请求有权接口；分享弹窗改用 `shareable-users`；`openShareModal`/`saveShare` 增函数级 `is_owner` 兜底。
- `AgentConfigModal.vue`：新增 `readonly` 模式（横幅 + 表单禁用 + `save`/重置 token/隧道增删 函数级 guard）。
- `SshManager.vue`：Agent/Gateway 下拉显示「属于 {owner_name}」。
- `logger.ts`：`console_log_level:<uid>` 账户级隔离 + 旧 key 迁移；`Login/Register` 登录后 `reloadLogLevel()`。
- i18n：新增 `admin.sharedReadonly`、`admin.sharedFromTag`（zh/en 对齐，**718 叶键**），`AGENTS.md` 同步。
- **D6 远程管理控制台收敛**：`SshManager.vue` 新增 `consoleAgents`，共享 Agent 不进「Agent 控制台」分组与测速目标；保留在新建连接下拉可选用。纯前端，无 i18n 新键。
- **D6 配套测试调整**：`autotest/tests/ssh-webrtc/webterm-local.spec.ts` 改为以本地 Agent **属主**账号登录（`WEBTERM_AGENT_USER`，默认 `inportb`）——控制台只显示自有 Agent 后，以 admin 登录无法再看到别人的 `local-agent*` 卡片。
