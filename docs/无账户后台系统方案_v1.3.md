# 无账户后台系统方案 v1.3

> 版本:v1.3(相对 v1.2 的变更:文档管理整合文件管理+MD编辑,网址管理增加分组,新增SSH管理)

## 1. 功能清单

| 功能 | 顶栏入口 | 说明 |
|---|---|---|
| 📖 文档管理 | 文档管理 | 左侧文件树(CRUD) + 右侧浏览/编辑模式切换(CodeMirror6) |
| 🔗 网址管理 | 网址管理 | 左侧分组列表(CRUD) + 右侧链接卡片网格 |
| 💻 SSH管理 | SSH管理 | 左侧连接列表(CRUD) + 右侧终端页签(xterm.js + WebSocket) |

## 3. 数据结构

### 3.1 links.json(分组结构)

```json
{
  "groups": [
    {"id":"g1","name":"前端","links":[
      {"id":"abc","title":"Vue3","url":"https://...","description":"","group_id":"g1"}
    ]}
  ]
}
```

- 旧格式(纯数组)自动迁移到新格式
- 分组一层,不嵌套

### 3.2 ssh_connections.json

```json
[
  {"id":"abc","name":"生产","host":"10.0.0.1","port":22,"username":"root",
   "auth_type":"password","password":"xxx","key_path":"","remark":""}
]
```

## 4. API 汇总

### 4.1 文件管理

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/files/tree` | 完整文件树 |
| GET | `/api/files/read?path=` | 读取文件 |
| POST | `/api/files/write` | 写入 `{path, content}` |
| POST | `/api/files/new` | 新建 `{parent, name, is_dir}` |
| POST | `/api/files/rename` | 重命名 `{old_path, new_name}` |
| POST | `/api/files/delete` | 删除 `{path}` |

### 4.2 链接管理(分组)

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/links` | 返回 `{groups:[...]}` |
| POST | `/api/links/add` | 添加 `{title,url,description,group_id}` |
| POST | `/api/links/update` | 更新 |
| POST | `/api/links/delete` | 删除 `{id}` |
| POST | `/api/links/group/add` | 新建分组 `{name}` |
| POST | `/api/links/group/rename` | 重命名 `{id,name}` |
| POST | `/api/links/group/delete` | 删除分组 `{id}` |

### 4.3 SSH 管理

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/ssh` | 列表(不含密码) |
| POST | `/api/ssh/add` | 新建 |
| POST | `/api/ssh/update` | 更新 |
| POST | `/api/ssh/delete` | 删除 `{id}` |
| POST | `/api/ssh/test` | 测试连接 |
| WS | `/ws/ssh` | WebSocket→SSH 双向桥接 |
