# 无账户后台系统方案 v1.2

> 主题:无账户 Markdown 文档浏览器后台系统(FastAPI + Vue3/Vite + Docker Compose)
> 版本:v1.2(相对 v1.1 的变更:新增网址编辑器、Markdown 编辑器、文件管理器;md 改为可读写挂载)

## 1. 功能清单

| 功能 | 入口(顶栏) | 说明 |
|---|---|---|
| 文档浏览 | 📖 文档浏览 | 三栏布局:顶栏分类 + 侧栏目录树 + 右侧 Markdown/Mermaid 渲染 |
| 网址编辑器 | 🔗 网址编辑器 | 卡片网格展示链接,弹窗编辑,标签过滤,数据存 `md/links.json` |
| Markdown 编辑 | ✏️ Markdown 编辑 | CodeMirror6 编辑器 + 实时预览,支持新建/保存/重命名/删除,文件列表侧栏 |
| 文件管理 | 📂 文件管理 | 目录树浏览,支持新建文件/目录、重命名、删除,点击 .md 文件跳转编辑器 |

## 3. 后端 API(新增)

### 3.1 文件管理

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/api/files/tree` | – | 扫描 md 目录树(含所有文件,不限 .md) |
| GET | `/api/files/read` | `path` | 读取文件内容(UTF-8) |
| POST | `/api/files/write` | `{path, content}` | 写入文件(不存在则创建) |
| POST | `/api/files/new` | `{parent, name, is_dir}` | 新建文件或目录 |
| POST | `/api/files/rename` | `{old_path, new_name}` | 重命名 |
| POST | `/api/files/delete` | `{path}` | 删除文件或目录 |
| POST | `/api/files/move` | `{src, dst_dir}` | 移动文件 |

### 3.2 链接管理

| 方法 | 路径 | 参数 | 说明 |
|---|---|---|---|
| GET | `/api/links` | – | 读取 links.json |
| POST | `/api/links/add` | `{title, url, description, tags}` | 新增链接(自动生成 id) |
| POST | `/api/links/update` | `{id, title, url, ...}` | 更新链接 |
| POST | `/api/links/delete` | `item_id` | 删除链接 |

## 5. 部署变更

```yaml
volumes:
  - ./md:/app/md    # 去掉 :ro,支持编辑/上传
```

`links.json` 存储在 `md/` 根目录,随文档目录一起备份。
