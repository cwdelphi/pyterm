# 无账户后台系统方案 v1.0

> 主题:无账户 Markdown 文档浏览器后台系统(FastAPI + Vue3/Vite + Docker Compose)
> 版本:v1.0(首个版本,后续修订按 `_v1.1`、`_v2.0` 新建文件,禁止覆盖旧版)

## 1. 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | Python 3.12 + FastAPI + uvicorn | 只读:目录树 API、文档读取 API、静态托管、路径安全校验;无账户、无数据库 |
| 前端 | Vue3 + Vite + TypeScript | `@vitejs/plugin-vue`;构建产物 `dist/` 由 Docker 多阶段拷入镜像 |
| 渲染 | markdown-it + highlight.js + mermaid | 客户端渲染;Mermaid 统一 `mermaid.run()` |
| 路由 | 内部状态路由(hash 无需后端回退) | 文档路径即路由 |
| 主题 | CSS 变量 + `prefers-color-scheme` + localStorage | 亮/暗/跟随系统 + 主题色(蓝/绿/紫) |
| 部署 | Dockerfile(多阶段) + docker-compose.yaml + .env | 单容器,`./md` 只读挂载 |

## 3. 后端 API

| 方法 | 路径 | 参数 | 返回 |
|---|---|---|---|
| GET | `/` | – | 托管 `dist/index.html`(SPA) |
| GET | `/api/tree` | – | 递归目录树:`{name,path,type,children[]}`,仅 `.md`,目录在前文件在后 |
| GET | `/api/doc` | `path` | 该 `.md` 文件内容 |
| GET | `/api/config` | – | `SITE_NAME`、首页文档路径 |

安全:对 `path` 做 `resolve()` 后校验 `is_relative_to(MD_ROOT)`,拒绝非 `.md`。

## 4. 前端 UX 界面设计

### 4.1 整体布局(桌面 ≥900px)

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 ●Logo | 00-欢迎 | 01-Markdown基础 | 02-示例   🌙 [主题▾] │
├──────────┬───────────────────────────────────────────────────┤
│ 侧栏     │ 面包屑: 首页 / 02-示例 / 流程图与界面      [↑][TOC] │
│ ▾ 02-示例├───────────────────────────────────────────────────┤
│   · 流程图│  Markdown 渲染区                                   │
│ ▸ 00-欢迎│   - 基础语法渲染                                   │
│ ▸ 01-…   │   - Mermaid 流程图/时序图(可横向滚动)              │
└──────────┴───────────────────────────────────────────────────┘
```

| 区域 | 交互 |
|---|---|
| 顶栏 | 一级菜单=顶层目录;当前高亮;超长横向滚动 |
| 侧栏 | 二级目录树(多级 ▸/▾);点击切文档;当前文件高亮 |
| 导航栏 | 面包屑逐级可点;回顶部;TOC 点击滚动锚点 |
| 内容区 | markdown-it + 代码高亮 + mermaid 图 |

### 4.2 主题切换

| 项 | 实现 |
|---|---|
| 模式 | ☀/☾/自动(跟随系统 `matchMedia`,实时响应) |
| 主题色 | 蓝/绿/紫,切换 `--accent` 变量 |
| 记忆 | `localStorage['themeMode']`、`localStorage['accent']` |
| Mermaid | 按模式 `initialize({theme})`,主题变化时重渲染 |
| 防闪 | `head` 内联脚本预置 `data-theme` |

### 4.3 移动端响应式

| 断点 | 行为 |
|---|---|
| <900px | 侧栏收为抽屉(汉堡开/遮罩关),内容区全宽 |
| <768px | 顶栏菜单横向滚动;面包屑压缩;表格/代码/mermaid `overflow-x:auto` |
| 触屏 | 点击目标 ≥44px |

## 5. 部署

```yaml
services:
  md:
    build: .
    container_name: pyterm_md
    ports: ["${HOST_PORT}:${PORT}"]
    volumes:
      - ./md:/app/md:ro
      - /etc/localtime:/etc/localtime:ro
      - /etc/timezone:/etc/timezone:ro
    environment:
      - TZ=Asia/Shanghai
      - SITE_NAME=${SITE_NAME}
    restart: unless-stopped
```

`.env`:`PORT=5588`、`HOST_PORT=5588`、`SITE_NAME=文档中心`。
`md` 只读挂载(:ro),改文件即改即见,无需重建容器。
