## 2. 实现要点

### 2.1 CORS（S7a）

- `app/main.py`：默认**不注册** CORS 中间件（同源部署：静态挂载 / vite proxy 无需 CORS）。
- 环境变量 `CORS_ORIGINS` 逗号分隔显式允许，如 `https://a.example,https://b.example`。
- 遗留 `allow_origins=["*"]` + `allow_credentials=True` 组合已移除。

### 2.2 JWT 不进 query（S7b）

- **网关→后端** `deriveVerifyBase()`：`GET /api/auth/verify` + `Authorization: Bearer`；不再拼 `?token=`（避免 access log 泄漏）。
- **浏览器→网关 WS**：`new WebSocket(url, ["bearer", jwt])`；服务端 `extractToken` 优先级：
  1. `Authorization: Bearer`
  2. `Sec-WebSocket-Protocol: "bearer", "<jwt>"`
  3. query `token`（旧客户端兼容）
- 服务端 `Upgrader.Subprotocols = ["bearer"]` 以回选协议。
- `/api/auth/verify` 本就支持 query 与 Authorization 双通道，网关改走头即可。

### 2.3 test_files_api 重写（债1）

- 原测试打 `/api/files/*`（`app/api.py` 死代码，未挂载）。
- 现网为 `/api/docs/*`（`api_isolated.py`，带鉴权）。
- MinIO 宿主不可达时：`upload_doc`/`download_doc`/`delete_doc` 打桩；测鉴权 401、tree 列表、write→read 往返、mkdir/rename/delete。
- 用户创建改用 `delete_user_by_username` + `register_user`，避免重复 username 冲突。

### 2.4 测试用户清理（债2）

- `_write_users_file`：对 `test_` / `docs_api_` / `iso_` 等测试前缀且不在名单内的用户执行删除（原先只 upsert 不删，残留导致 1062）。
- 新增 `delete_user_by_username`：级联删 SshConnection/Document 后删用户。
