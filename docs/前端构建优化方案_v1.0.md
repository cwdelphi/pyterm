## 三、优化方案

### P0: 构建速度 + 缓存

| 优化项 | 预期效果 | 实现 |
|--------|----------|------|
| Terser → esbuild | 构建时间 -50%~70% | `minify: 'esbuild'` |
| Nginx 静态缓存 | 二次访问秒开 | `Cache-Control: public, immutable` |

### P1: 减小包体积

| 优化项 | 预期节省 | 实现 |
|--------|----------|------|
| highlight.js 按语言引入 | ~250 KB | `hljs/lib/core` + 按需注册 |
| 排除不需要的 mermaid 图表 | ~1-2 MB | `manualChunks` + 动态 import |
| 排除 KaTeX | ~257 KB | mermaid 配置 `math: false` |

### P2: 进阶优化

| 优化项 | 预期效果 | 实现 |
|--------|----------|------|
| manualChunks 显式配置 | 更好的缓存粒度 | vue/codemirror/mermaid 独立 chunk |
| mermaid 按需加载 | 按需加载图表类型 | 动态 import 图表定义 |

## 四、Nginx 缓存策略

| 资源类型 | 缓存策略 |
|----------|----------|
| `assets/*.js` (带哈希) | `Cache-Control: public, max-age=31536000, immutable` |
| `assets/*.css` (带哈希) | `Cache-Control: public, max-age=31536000, immutable` |
| `index.html` | `Cache-Control: no-cache` (每次验证) |
| `api/*` | 保持 `no-cache` (动态内容) |
