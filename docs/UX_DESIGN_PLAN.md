# 泡鱼终端 — 统一界面风格UX设计方案 v1.0

## 基于截图分析的问题清单

| # | 问题 | 位置 | 严重度 |
|---|------|------|--------|
| 1 | 表格无卡片容器 | Agent/用户/coturn/审计/网关 | 高 |
| 2 | 页面标题不一致(网关重复标题) | 网关管理 | 中 |
| 3 | 大面积空白(密码/Agent配置) | 密码管理/Agent配置 | 中 |
| 4 | 空状态设计不统一 | SSH管理/各empty态 | 中 |
| 5 | 操作列按钮拥挤(5个) | Agent管理 | 中 |
| 6 | 时间格式不友好(ISO原始) | 审计日志 | 低 |
| 7 | 侧栏偏窄(180px) | 系统管理 | 低 |

## 实施计划

### Phase 1: 表格卡片容器 (1天)
- 所有表格包裹在 .table-card 中
- 圆角12px + 边框 + 内边距
- 表头大写字母 + 背景色

### Phase 2: 页面标题统一 (0.5天)
- 统一 h2 标题 + 描述
- 修复网关重复标题

### Phase 3: 空白页面填充 (0.5天)
- 密码管理改为居中卡片
- SSH空状态加图标

### Phase 4: Agent操作列优化 (0.5天)
- 主要操作蓝色/次要灰色/危险红色

### Phase 5: 审计日志时间格式化 (0.5天)
- ISO → 09-19 01:26

### Phase 6: 侧栏微调 (0.5天)
- 180px → 200px
