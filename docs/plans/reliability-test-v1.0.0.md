## 已知风险

| 问题 | 风险等级 | 依据 |
|------|---------|------|
| Gateway pendingMsgs 溢出丢消息 | 高 | maxPendingMsgs=1000 硬编码 |
| 心跳无超时断开 | 中 | agent 侧无超时检测 |
| WS 断开后 DC 未关闭 | 中 | WS close 不一定触发 DC cleanup |
| 并发连接 diagReported 竞争 | 中 | 无锁，并发下可能重复上报 |
| Agent SSH 10s 超时 | 低 | 硬编码，慢网络可能误超时 |
