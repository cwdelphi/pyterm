# 无账户后台系统方案 v1.1

> 主题:无账户 Markdown 文档浏览器后台系统(FastAPI + Vue3/Vite + Docker Compose)
> 版本:v1.1(相对 v1.0 的变更:部署方式由「多阶段构建→拷入镜像」改为「镜像只装依赖,配置/代码/资源全部卷挂载」)

## 1. 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | Python 3.12 + FastAPI + uvicorn | 只读:目录树 API、文档读取 API、静态托管、路径安全校验;无账户、无数据库 |
| 前端 | Vue3 + Vite + TypeScript | `@vitejs/plugin-vue`;构建产物 `web/dist/` 在**宿主机**构建,挂载进容器 |
| 渲染 | markdown-it + highlight.js + mermaid | 客户端渲染;Mermaid 统一 `mermaid.run()` |
| 主题 | CSS 变量 + `prefers-color-scheme` + localStorage | 亮/暗/跟随系统 + 主题色(蓝/绿/紫) |
| 部署 | Dockerfile(仅依赖) + docker-compose.yaml(全挂载) + .env | 镜像不含业务代码,`.env` 经 `env_file` 注入 |

## 3. 后端 API

| 方法 | 路径 | 参数 | 返回 |
|---|---|---|---|
| GET | `/` | – | 托管 `web/dist`(SPA) |
| GET | `/api/tree` | – | 递归目录树 `{name,path,type,children[]}`,仅 `.md`,目录在前 |
| GET | `/api/doc` | `path` | 该 `.md` 文件内容(需 URL 编码) |
| GET | `/api/config` | – | `SITE_NAME`、首页文档路径 |

安全:`path` 经 `resolve()` 校验 `is_relative_to(MD_ROOT)`;拒非 `.md`;APP 只读挂载。

### 4.1 布局(桌面 ≥900px)

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 ●Logo | 00-欢迎 | 01-Markdown基础 | 02-示例   ☀/☾ [主题▾] │
├──────────┬───────────────────────────────────────────────────┤
│ 侧栏     │ 面包屑: 首页 / 02-示例 / 流程图与界面    [目录][回顶]│

│   · 流程图│  Markdown 渲染区(代码高亮/表格/引用)              │
│ ▸ 00-欢迎│   Mermaid 流程图/时序图/类图/甘特图等              │
└──────────┴───────────────────────────────────────────────────┘
```

| 区域 | 交互 |
|---|---|
| 顶栏 | 一级菜单=顶层目录;当前高亮;超长横向滚动 |
| 侧栏 | 二级目录树(递归多级 ▸/▾);点击切文档;当前高亮 |
| 导航栏 | 面包屑逐级可点;目录 TOC 浮层;回顶 |
| 内容区 | markdown-it + highlight.js + mermaid,图容器可横向滚动 |

### 4.2 主题切换

| 项 | 实现 |
|---|---|
| 模式 | ☀(亮)/ ☾(暗)/ 自动(跟随系统 `matchMedia`,实时响应) |
| 主题色 | 蓝/绿/紫,切换 `--accent` 系列变量 |
| 记忆 | `localStorage['themeMode']`、`localStorage['accent']` |
| Mermaid | 按模式 `initialize({theme})`,暗色切换重渲染 |
| 防闪 | `index.html` 内联脚本预置 `data-theme` |

### 4.3 移动端响应式

| 断点 | 行为 |
|---|---|
| <900px | 侧栏收为抽屉(汉堡开/遮罩关),内容区全宽 |
| <640px | 顶栏菜单横向滚动;表格/代码/mermaid `overflow-x:auto`;面包屑压缩 |
| 触屏 | 可点目标 ≥44px |

## 5. 部署(重点:全挂载)

```yaml
services:
  md:
    build: .
    image: pyterm/md:latest
    container_name: pyterm_md
    ports: ["${HOST_PORT:-5588}:${PORT:-5588}"]
    volumes:
      - ./app:/app/app:ro
      - ./web/dist:/app/static:ro
      - ./md:/app/md:ro
      - /etc/localtime:/etc/localtime:ro
      - /etc/timezone:/etc/timezone:ro
    env_file:
      - .env
    environment:
      - TZ=Asia/Shanghai
    restart: unless-stopped
```

| 要点 | 说明 |
|---|---|
| 镜像是傻鸟化 | Dockerfile 只 `pip install`,不含业务代码 |
| 配置 | `.env` 经 `env_file` 注入容器;端口/站点名改 `.env` 后 `docker compose up -d` 生效 |
| 代码 | `app/`、`web/dist/` 只读挂载;**前端改动需先在宿主 `npm run build`**,后端改动无需重建 |
| 资源 | `md/` 只读挂载,加/改文档即改即见 |
| 一键重建 | `docker compose up -d --build`(仅当依赖变更时需重建镜像) |

### 5.1 常用命令

```bash
# 宿主构建前端
cd web && npm install --registry=https://registry.npmmirror.com && npm run build

# 启动/更新(配置、资源改动无需加 --build)
docker compose up -d

# 依赖变更后才需要重建镜像
docker compose up -d --build
```
