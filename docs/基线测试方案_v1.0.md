# 基线测试包方案 v1.0

## 一、测试架构

```
pyterm/
├── app/tests/                          # 后端 pytest 测试
│   ├── conftest.py                     # 共享fixtures
│   ├── test_auth_api.py                # 认证API (8用例)
│   ├── test_admin_api.py               # 管理员API (5用例)
│   ├── test_webrtc_api.py              # WebRTC信令API (4用例)
│   ├── test_api_isolated.py            # 隔离API (6用例)
│   ├── test_files_api.py              # [已有]
│   ├── test_links_api.py              # [已有]
│   ├── test_ssh_api.py                # [已有]
│   └── test_config_api.py             # [已有]
├── autotest/tests/                     # Playwright E2E
│   ├── auth-register.spec.ts          # 注册流程 (5用例)
│   ├── auth-login.spec.ts             # 登录流程 (5用例)
│   ├── auth-flow.spec.ts              # 完整认证流程 (4用例)
│   ├── agent-manager.spec.ts          # Agent管理 (4用例)
│   ├── screenshot-baseline.spec.ts    # 全站截图 (1用例)
│   └── [已有7个spec文件]
├── run-baseline-tests.sh              # 一键测试脚本
└── docs/基线测试方案_v1.0.md           # 本文档
```

## 五、运行方式

```bash
./run-baseline-tests.sh                    # 一键运行
python -m pytest app/tests -v --tb=short   # 后端
cd web && npm test                         # 前端单元
cd autotest && npx playwright test         # E2E
```
